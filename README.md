# Экспертная система подбора направления в КФУ

Telegram-бот, который помогает абитуриенту выбрать образовательную программу в Казанском федеральном университете. Бот задаёт вопросы об интересах, школьных предметах и ЕГЭ, сужает выбор по дереву направлений, задаёт персональные уточняющие вопросы и предлагает конкретную программу с объяснением, почему она подходит.

**База:** 24 института, 280 программ бакалавриата и специалитета в Казани, Набережных Челнах и Елабуге, 189 программ магистратуры.

## Как это работает

1. **Анкета:** город обучения, уровень (бакалавриат или магистратура), иностранный абитуриент или нет, интересы, любимые предметы, только бюджет или нет.
2. **ЕГЭ:** если экзамены сданы, бот спрашивает предметы и баллы и сверяет их с минимальными баллами КФУ и требованиями институтов. Если ещё нет, после выбора направления подсказывает, какие экзамены сдавать.
3. **Направление:** абитуриент выбирает область по дереву направлений («ИТ», «Науки о Земле» → «Физика» и т. д.), которое сводится к набору институтов.
4. **Персональные вопросы:** языковая модель составляет 3–4 вопроса именно о различиях между программами-кандидатами.
5. **Подбор:** модель выбирает **номер** программы из заранее отфильтрованного списка (по городу, уровню, бюджету, форме обучения). Название, код, профиль, срок и число мест берутся из базы, а не из ответа модели, поэтому выдуманных программ в ответе быть не может. Отдельный валидатор заменяет названия институтов на реальные.
6. **Альтернативы:** по кнопке бот предлагает другие подходящие программы.

## Технологии

- Python, pyTelegramBotAPI.
- Языковые модели: Yandex GPT, Qwen или Gemini, переключаются настройкой.
- Docker и автодеплой через GitHub Actions: сборка образа → GitHub Container Registry → обновление на сервере по SSH.

## Запуск

```bash
pip install -r requirements.txt
cp .env.example .env   # вписать TELEGRAM_BOT_TOKEN и ключ выбранной модели
python bot.py
```

Переменные в `.env`:

- `TELEGRAM_BOT_TOKEN` — токен бота от @BotFather;
- `YANDEX_FOLDER_ID`, `YANDEX_AUTH_TOKEN` — для Yandex GPT;
- `QWEN_API_KEY`, `GEMINI_API_KEY` — для Qwen и Gemini (необязательно);
- `DEFAULT_LLM_MODEL` — `yandex`, `qwen` или `gemini`;
- `LOG_LEVEL` — уровень логирования.

Через Docker:

```bash
docker compose build
IMAGE=kpfu-edu-bot TAG=latest docker compose up -d
```

## Автодеплой

При пуше в `main` workflow `.github/workflows/deploy.yml` собирает образ, публикует его в `ghcr.io` и обновляет контейнер на сервере. Для этого в настройках репозитория (Settings → Secrets and variables → Actions) нужны секреты `DEPLOY_HOST`, `DEPLOY_USER`, `DEPLOY_SSH_KEY` и при необходимости `DEPLOY_PATH` (по умолчанию `/opt/kpfu-bot`) и `DEPLOY_PORT`. На сервере должны быть Docker, `docker-compose.yml` и заполненный `.env`. Шаг деплоя включается переменной репозитория `DEPLOY_ENABLED=true` (там же, вкладка Variables); без неё собирается и публикуется только образ.
